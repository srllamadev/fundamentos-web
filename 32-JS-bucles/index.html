Bucles en JavaScript

En esta lección aprenderemos a repetir bloques de código usando estructuras de bucle (for, while, do...while y for...of). Los bucles nos permiten ejecutar tareas repetitivas de forma eficiente, combinando todo lo aprendido en las lecciones anteriores: variables, tipos de datos, operadores y condicionales.

Abre la consola del navegador (F12) para ver todos los resultados.
