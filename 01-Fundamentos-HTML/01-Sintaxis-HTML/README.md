## Bienvenidos al curso de HTML

Este repositorio contiene **6 lecciones progresivas** donde aprenderás las etiquetas fundamentales de HTML construyendo el perfil profesional de **Yamil N**, un ingeniero industrial con 8 años de experiencia. Cada lección se enfoca en un grupo específico de etiquetas y puedes copiar el código para practicar.

## Conceptos clave que aprenderás

### Etiquetas y atributos

```html
<etiqueta atributo="valor">Contenido</etiqueta>
```

- **Etiqueta**: indica qué tipo de elemento es (`<h1>`, `<p>`, `<div>`, etc.)
- **Atributo**: información adicional del elemento (`id`, `class`, `src`, `href`, etc.)
- **Contenido**: lo que va entre la etiqueta de apertura y cierre

### Reglas fundamentales

1. **Un solo `<h1>` por página** - Los demás títulos van de `<h2>` en adelante
2. **Toda `<img>` debe tener `alt`** - Por accesibilidad y SEO
3. **Todo `<label>` debe tener `for` que coincida con el `id` del `<input>`** - Por usabilidad
4. **Usar `<div>` para bloques y `<span>` para línea** - No mezclarlos
5. **El esqueleto básico es obligatorio** - `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`
