1. calc() - La Calculadora

Permite mezclar unidades como px, %, rem, vw en operaciones matematicas.

padding: calc(1rem + 8px);
width: calc(100% - 200px);
margin-top: calc(2rem * 1.5);

Esta barra superior usa: padding: calc(1rem + 8px) calc(2rem + 10px)

2. clamp() - Control Total del Tamanio

Define un valor minimo, uno ideal y uno maximo. El navegador elige automaticamente segun el viewport.

font-size: clamp(1.5rem, 5vw, 3rem);
max-width: clamp(300px, 60%, 700px);
padding: clamp(1rem, calc(1rem + 2vw), 3rem);

Redimensiona la ventana y observa como el titulo cambia suavemente entre 1.5rem y 3rem.

3. min() - Limite Superior

Elige el valor mas pequenio. Ideal para "nunca mas grande que X".

width: min(100%, 500px);
padding: min(5vw, 32px);

La tarjeta de perfil usa width: min(100%, 500px) - en movil ocupa todo el ancho, en escritorio se limita a 500px.

4. max() - Limite Inferior

Elige el valor mas grande. Ideal para "siempre al menos X".

width: max(250px, 30%);

La barra lateral usa width: max(250px, 30%) - garantiza un minimo legible incluso en pantallas pequenias.

6. Combinacion Avanzada

Las funciones se pueden combinar entre si para lograr un control total:

padding: clamp(1rem, calc(1rem + 2vw), 3rem);
font-size: clamp(0.85rem, calc(0.75rem + 0.5vw), 1.1rem);
