1. Tamanos de Fuente (font-size)

12px: Texto pequeno para notas al pie o detalles secundarios
16px: Texto base para parrafos y contenido general
20px: Texto ligeramente grande para subtitulos
24px: Texto grande para titulos de seccion
32px: Texto muy grande para titulos principales
40px: Texto enorme para hero o encabezados destacados

2. Pesos de Fuente (font-weight)

300 (Light): Peso ligero, ideal para texto secundario o elegante
400 (Normal): Peso normal, el estandar para texto regular
600 (Semi-bold): Semi-negrita, bueno para subtitulos destacados
700 (Bold): Negrita, para titulos importantes y enfasis fuerte
