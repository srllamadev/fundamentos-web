# 02 - El Corazon de CSS

## Resumen de la seccion

Aqui entramos al **corazon de CSS**. Ya no basta con cambiar colores y fuentes: ahora aprenderas como CSS **piensa, decide y organiza** los elementos en pantalla.

Si HTML es el esqueleto de una pagina, CSS es su **sistema nervioso**: controla que todo se vea bien, que las reglas se respeten en orden, y que cada elemento ocupe su lugar.

## Por que esta seccion es importante

Despues de estas 3 lecciones tendras las bases solidas para:

- Entender **por que** un estilo se aplica o no se aplica.
- Calcular **cual regla gana** cuando dos apuntan al mismo elemento.
- Controlar **como se comportan** los elementos en pantalla (bloque, linea, invisibles).
- Resolver el 90% de los problemas comunes de maquetacion.

Sin esto, CSS parece magia negra. Con esto, CSS es **logica pura**.
