1. Contraste de Colores (WCAG)

El contraste es la diferencia de luminosidad entre texto y fondo. WCAG exige un ratio minimo de 4.5:1 para texto normal y 3:1 para texto grande.

#1a5276 sobre #f5f5f5

Ratio 7.2:1

✅ Bien Contraste correcto, ratio 7.2 a 1

#333333 sobre #ffffff

Ratio 12.6:1

✅ Excelente Contraste excelente, ratio 12.6 a 1

#bdc3c7 sobre #ffffff

Ratio 1.6:1

❌ Ilegible Contraste insuficiente, ratio 1.6 a 1, no cumple WCAG

#f39c12 sobre #ffffff

Ratio 2.4:1

⚠️ Solo grande Contraste bajo, solo valido para texto grande o iconos
Regla: El color acento (#f39c12) sobre blanco solo alcanza ratio 2.4:1. Por eso se usa para elementos grandes o decorativos, nunca para texto pequenio.

2. Focus States Visibles

Navega con Tab para ver los diferentes estilos de focus. Nunca elimines el outline sin proveer una alternativa visible.

/* Outline solido */
.boton:focus-visible { outline: 4px solid #f39c12; }

/* Sombra */
.boton:focus-visible { box-shadow: 0 0 0 4px #f39c12; }

/* Cambio de fondo */
.boton:focus-visible { background: #1a5276; color: #fff; }

3. prefers-reduced-motion

Algunas personas sufren mareos con animaciones. CSS puede detectar su preferencia y desactivarlas.

Esta caja tiene una animacion fade-in.

Si tu sistema tiene "Reducir movimiento" activado, aparece instantaneamente.

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
Tip: Activa "Reducir movimiento" en la configuracion de tu sistema operativo para probar este comportamiento.
