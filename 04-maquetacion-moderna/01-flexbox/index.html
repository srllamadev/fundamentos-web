6. Sidebar + Contenido principal

La sidebar tiene ancho fijo y el contenido principal crece para llenar el espacio disponible con flex-grow: 1:

Panel de Control

  • Produccion
  • Inventario
  • Personal
  • Reportes
  • Configuracion

Contenido Principal (flex-grow: 1)

Este area crece automaticamente para llenar el espacio disponible despues de la sidebar.

En TextilPro, este layout se usa en el dashboard de produccion donde la sidebar muestra las secciones y el area principal muestra graficos y datos de las lineas de ensamblaje.

La clave es flex-grow: 1 en el contenido y flex-shrink: 0 en la sidebar para que no se encoja.
