1. position: static (por defecto)

Todos los elementos tienen position: static automaticamente. Se apilan en el flujo normal del documento.

Caja 1 - Orden natural
Caja 2 - Sigue el flujo
Caja 3 - Al final

Regla: Las propiedades top, left, right, bottom NO funcionan con static.

2. position: relative

El elemento se desplaza respecto a su posicion original, pero sigue ocupando ese espacio en el flujo.

Caja A - Posicion original (no se mueve)
Caja B - Movida con relative (top: 20px, left: 40px)
Caja C - El espacio de B sigue reservado

3. position: absolute

El elemento se saca del flujo y se posiciona respecto al ancestro con position diferente de static.

ABSOLUTE: top: 10px, right: 10px

El hijo absolute se posiciono en la esquina superior derecha del padre.

El padre tiene position: relative para crear un contexto de posicionamiento.

El contenido normal NO se ve afectado por el elemento absolute.

Caso practico: Badge de notificacion

Un uso muy comun de absolute es crear badges sobre iconos:

🔔 3

El badge "3" usa position: absolute respecto al contenedor del icono.

4. position: fixed

El elemento se ancla a la ventana del navegador (viewport). No se mueve al hacer scroll.

El header de esta pagina usa position: fixed - mira arriba, siempre esta visible.

El boton "volver arriba" de la esquina inferior derecha usa position: fixed.

Usos comunes:

  • Barras de navegacion fijas
  • Botones flotantes
  • Modales y overlays
  • Chat widgets

5. position: sticky

Es un hibrido: se comporta como relative hasta que llegas a cierto punto del scroll, y luego se comporta como fixed.
