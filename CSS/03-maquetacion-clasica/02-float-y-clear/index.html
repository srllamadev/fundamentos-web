1. El proposito original: texto alrededor de imagenes

float fue creado para que el texto fluya alrededor de un elemento, como en las revistas impresas.

float: left

Este texto fluye naturalmente alrededor de la imagen flotante a la izquierda. Asi es como funcionaban las revistas impresas de TextilPro: ponian una foto del producto y la descripcion lo rodeaba.

La propiedad margin-right en la imagen evita que el texto quede pegado a ella. Este es el uso correcto y vigente de float en CSS moderno.

Observa como el texto se adapta automaticamente al espacio disponible junto a la imagen, creando un flujo de lectura natural.

2. El colapso del contenedor (problema)

Cuando todos los hijos de un contenedor tienen float, el padre colapsa su altura a 0:

SIN clearfix (altura = 0):

PADRE con borde dashed rojo (colapsado!)
Float 1
Float 2
Float 3

El borde rojo del padre no envuelve a los hijos. La altura es 0 porque los hijos "escaparon" del flujo.

CON clearfix (altura correcta):

PADRE con borde verde (clearfix aplicado)
Float 1
Float 2
Float 3

El clearfix (::after con clear: both) obliga al padre a "ver" a sus hijos y envolverlos correctamente.

3. clear: evitar que un elemento fluya junto a flotantes

clear: both fuerza al elemento a pasar por debajo de cualquier flotante.

float: left
float: right
Este tiene clear: both (pasa debajo)
float: left
float: right
Este NO tiene clear (se sube entre los flotantes)
