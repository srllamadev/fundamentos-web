# Seccion 05: Estilo y Presentacion

Bienvenido a la seccion donde tu HTML deja de ser solo estructura y empieza a tener **personalidad visual**.

---

## ¿Que veremos en esta seccion?

Piensa en HTML como los huesos de una persona y CSS como la piel, la ropa y el estilo. Hasta ahora hemos construido el esqueleto. Ahora le vamos a dar vida visual.

### Contenido de la seccion

| Subtema | ¿Que aprenderas? | Analogia |
|---------|------------------|----------|
| **01-tipografia** | Fuentes, tamanos, pesos, Google Fonts | Elegir la "tipografia" de un libro |
| **02-fondos-bordes-sombras** | Backgrounds, bordes, sombras de caja y texto | El "marco" y "ambiente" de una fotografia |
| **03-efectos-visuales** | Opacidad, bordes redondeados, filtros, transiciones | Los "efectos especiales" de una pelicula |

---

## ¿Por que importa el estilo?

Yamil N trabaja en **TextilPro S.A.** presentando reportes de produccion a la gerencia. Si su reporte web se ve como un documento de los anos 90, nadie lo toma en serio. Pero si tiene tipografia clara, fondos agradables y efectos sutiles, el mensaje llega mejor.

```
SIN ESTILO:                    CON ESTILO:
┌─────────────────────┐       ┌─────────────────────┐
│ Reporte de Produccion│       │ ┌─────────────────┐ │
│                     │       │ │  Reporte de      │ │
│ Texto plano...      │       │ │  Produccion      │ │
│ Aburrido...         │       │ │                  │ │
│                     │       │ │  Texto elegante  │ │
└─────────────────────┘       │  con sombra suave  │ │
                              └─────────────────────┘ │
                              Fondo limpio, bordes    │
                              redondeados, colores    │
                              corporativos            │
                              └─────────────────────┘
```

---

## Reglas de oro de esta seccion

| # | Regla | Por que |
|---|-------|---------|
| 1 | **Menos es mas** | No abuses de sombras, colores y efectos |
| 2 | **Consistencia** | Usa la misma paleta de colores en todo el proyecto |
| 3 | **Legibilidad primero** | El texto debe ser facil de leer siempre |
| 4 | **Accesibilidad** | Contraste adecuado entre texto y fondo |
| 5 | **Mobile-first** | Disena pensando primero en pantallas pequenas |
