Cascada y Especificidad

1. Tag vs Clase 0-1-0 gana a 0-0-1

Este parrafo tiene class="perfil". La regla p dice rojo, pero .perfil dice azul oscuro. La clase gana.

Yamil N - Ingeniero Industrial de Bolivia. Este texto es azul oscuro porque .perfil (0-1-0) gana sobre p (0-0-1).

2. Clase vs ID 1-0-0 gana a 0-1-0

La clase dice fondo azul claro, pero el ID dice fondo naranja. El ID gana siempre.

Perfil de Yamil N: Ingeniero Industrial. Este fondo es naranja porque el ID #perfil-yamil gana sobre .tarjeta-perfil.

3. Mismo selector, diferente orden 0-1-0 = 0-1-0, ultimo gana

Dos reglas con .nombre. La primera dice 18px, la segunda 28px. Ambas tienen la misma especificidad, pero la ultima escrita gana.

Yamil N

Este texto tiene 28px porque la segunda regla .nombre gano por orden.

4. !important: el martillo !important gana sobre todo

La clase .texto-normal dice azul, pero .texto-fuerte tiene !important y dice rojo.

Este texto es rojo porque !important siempre gana. Yamil N - Bolivia.

5. Herencia color y font-family se heredan

El contenedor padre tiene color: #1a5276 y font-family: Georgia. Los hijos heredan estos valores automaticamente.

Este parrafo hereda el color y la fuente del padre. Yamil N - Ingeniero Industrial.

Pero el background-color NO se hereda: este span tiene fondo transparente.

6. Especificidad combinada 0-1-1 gana a 0-1-0

div.tarjeta .titulo-seccion tiene especificidad 0-1-1, mayor que .titulo-seccion solo (0-1-0).

Este titulo es azul porque el selector combinado gana

7. Orden vs Especificidad 1-0-0 gana a 0-1-0 siempre

Aunque .orden-a aparece antes, #orden-b tiene ID (1-0-0) y gana sin importar el orden.

Yamil N - Este texto es naranja porque el ID gana, no importa que la clase apareciera antes.
