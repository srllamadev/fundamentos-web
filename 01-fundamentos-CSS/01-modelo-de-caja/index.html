Modelo de Caja (Box Model)

¿Que es el Modelo de Caja?

TODO elemento HTML es una caja con 4 capas: contenido, padding, border y margin.

Diagrama del Modelo de Caja

MARGIN (espacio exterior)
BORDER (borde)
PADDING (espacio interior)
CONTENIDO (texto, imagenes)

Ejemplo Visual de una Caja

Esta caja tiene: padding: 40px, margin: 30px, border: 5px solid #2e86c1.

El contenido esta separado del borde por el padding (40px).

La caja esta separada de las demas por el margin (30px).

El Problema de width sin box-sizing

Sin box-sizing: border-box, el width NO incluye padding ni border:

width: 300px + padding: 30px*2 + border: 5px*2 = 370px de ancho real

Con box-sizing: border-box, el width SI incluye padding y border:

width: 300px (incluye padding y border) = 300px de ancho real

Efecto del Margin

Esta caja tiene margin: 40px. Nota el espacio alrededor.

Esta caja tiene margin: 0. No hay espacio exterior.

La Solucion: box-sizing global

*, *::before, *::after {
    box-sizing: border-box;
}

Esta regla hace que TODOS los elementos usen border-box. Es la practica estandar moderna.
