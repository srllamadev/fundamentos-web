Propiedad display

1. display: block block

Los elementos block ocupan TODO el ancho disponible y empiezan en una linea nueva.

Bloque 1: Yamil N - Ingeniero Industrial (width: 400px)
Bloque 2: Cada bloque empieza en una linea nueva
Bloque 3: width: 250px (mas corto)

Cada bloque ocupa su propia linea y acepta width, height, margin, padding.

2. display: inline inline

Los elementos inline se quedan en la misma linea que el texto. Span 1 Aceptan padding horizontal pero Span 2 NO aceptan width ni height.

Intento fallido de dar tamano a un inline:

Este span dice width: 300px pero NO funciona

El span con width: 300px y height: 100px se ve del tamano normal del texto. Esas propiedades se ignoran en display: inline.

3. display: inline-block inline-block

Lo mejor de ambos mundos: se quedan en linea pero aceptan width y height.

Perfil: Yamil N
Profesion: Ingeniero
Pais: Bolivia

Las 3 cajas estan en la misma linea. Cada una tiene width: 180px y height: 80px. inline-block permite esto.

4. display: none vs visibility: hidden none / hidden

display: none elimina el elemento del layout. visibility: hidden lo hace invisible pero deja el hueco.

Elemento A: Visible (Yamil N - La Paz, Bolivia)
[Este elemento tiene display: none. No se ve y no ocupa espacio.]
Elemento C: Esta pegado a A porque B no ocupa espacio.
Elemento D: Visible
[Este elemento tiene visibility: hidden. No se ve pero ocupa espacio.]
Elemento F: Hay un espacio arriba porque E ocupa su lugar.

Arriba: entre A y C no hay espacio (B tiene display:none). Entre D y F si hay hueco (E tiene visibility:hidden).

5. Links como botones inline-block

Un <a> es inline por defecto. Con display: inline-block podemos hacerlo boton.

Los links son ahora botones con padding, background, border-radius. Todo gracias a display: inline-block.

Resumen: Tabla de comparacion

Propiedad              block    inline   inline-block   none
--------------------------------------------------------------
Linea nueva             Si       No         No           -
Ocupa todo el ancho     Si       No         No           -
Acepta width            Si      NO          Si           -
Acepta height           Si      NO          Si           -
Acepta margin (todos)   Si    Solo horiz    Si           -
Acepta padding (todos)  Si    Solo horiz*   Si           -
Se queda en linea       No       Si         Si           -
Ocupa espacio           Si       Si         Si          NO

*El padding vertical en inline se aplica visualmente pero puede afectar la linea de texto.
